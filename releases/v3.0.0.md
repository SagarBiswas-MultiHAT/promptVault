# PromptVault v3.0.0: The Commercial Prompt Engineering Workstation

Welcome to **PromptVault v3.0.0**, our most significant milestone to date! PromptVault has evolved from an offline-first prompt library into a complete **commercial-grade Prompt Engineering Workstation** featuring Git-style prompt version control, multi-tier licensing powered by Polar.sh, an offline-first notification architecture, and a comprehensive suite of 371 passing automated tests.

---

## 🌟 What Is New in v3.0.0

### 1. 🌿 Git-Style Prompt Version Control & LCS Diff Engine
Never lose a high-performing prompt variation again. PromptVault now embeds a zero-dependency, pure TypeScript diff engine directly into your workflow:
- **Longest Common Subsequence (LCS) Algorithm**: Fast character, word, and line diff calculations with real-time addition and deletion (+ / -) metrics.
- **Split & Unified Diff Views**: Toggle smoothly between side-by-side split comparison and unified inline diffs.
- **Zero-Knowledge Revision Snapshots**: Snapshots are encrypted directly within your vault prompt envelopes using AES-256-GCM. Supabase multi-device sync works seamlessly without requiring database migrations.
- **Version Control Controls**: Deterministic 6-character commit hashes, automatic contextual commit messages, custom commit notes, sliding-window retention pruning, explicit revision pinning, and non-destructive rollbacks.
- **Fork Revision as New Prompt**: Instantly fork any historical snapshot into a new standalone prompt in one click.

### 2. 💳 Commercial 4-Tier Licensing & Polar.sh Billing
PromptVault now offers a flexible monetization framework for individual creators, power users, and engineering teams:
- **Free Tier ($0)**: Generous 100-prompt capacity, 3 revisions per prompt, and 5 daily in-chat injections.
- **Pro Tier ($19 Lifetime)**: 1,000-prompt capacity, 25 revisions per prompt, unlimited daily injections, split-diff comparison, revision pinning, and custom commit notes.
- **Ultra Tier ($39 Lifetime)**: Unlimited prompts, 100 revisions per prompt, priority AI Librarian refinement, and advanced analytics.
- **Team Tier**: Multi-seat deployment with centralized billing, shared prompt repositories, and priority technical support.
- **Cryptographic Verification**: Native HMAC-SHA256 dual-engine license key generator and constant-time verifier with online heartbeat revalidation and offline resilience.
- **Official Polar.sh Integration**: Seamless checkout routing via `buy.polar.sh` with instant license activation and self-service customer portal management.

### 3. 🔔 Offline-First Notification Center & In-App Routing
Stay informed about security updates, system specs, and commercial tier limits without leaving your local environment:
- **Zero-Knowledge Seeding**: Essential security architecture notices and subscription plan overviews are automatically seeded offline during vault initialization.
- **Real-Time Badge Sync**: Extension and desktop headers stay in sync with reactive unread badge counters.
- **In-App Route Resolvers**: Hash anchors (`#pricing`, `#security`, `#terms`, `#privacy`, `#refund`) and path routes (`/pricing`, `/plans`, `/upgrade`) route directly into native dialogs without external page reloads.
- **16-Feature Comparison Matrix**: An interactive, collapsible comparison matrix detailing feature availability across all four tiers.

### 4. 📱 Responsive PWA Ergonomics & Inline Categories
- **Sub-1280px Adaptive Breakpoints**: Desktop header controls now gracefully adapt on laptops, collapsing secondary badges to clean icons to prevent search bar clipping.
- **Instant Category Creation**: Create categories on the fly directly inside the prompt modal dropdown ("+ Create Category...") with Enter to save, Escape to cancel, and duplicate detection.
- **Unified Form Dimensions**: Standardized input heights and baseline alignments across categories, tags, and search bars.
- **Mobile Experience**: Full-width popover panel with backdrop dismissal for the notification center.

### 5. 🛡️ Enterprise Security & Test Expansion
- **371 Passing Tests**: Automated test coverage expanded from 141 tests in 18 suites to 371 tests across 46 test suites, including comprehensive Playwright cross-browser and mobile specifications.
- **Zero Vulnerabilities**: Verified 0 vulnerabilities across all dependencies via strict npm audit checks.
- **Store Production Assets**: Automated framing scripts and promotional media for the official Microsoft Edge Add-ons Store.
